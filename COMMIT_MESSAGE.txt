Migrate the final four screens to the shared UI design system; strip all background PNGs

Final phase of the Notion-inspired UI redesign. Predecessors: the
idle/homepage pilot plus wifi/email/scanner (KIOSK_UI_REDESIGN_SESSION_SUMMARY.md),
then a pass that migrated usb/print_options/file_browser/payment. Not tied
to a roadmap-planning.txt phase — this is the UI/UX migration finishing the
last unmigrated surfaces and removing every full-window background image
from the app. User decisions for this pass: plain white body + Header
everywhere with the background PNGs deleted entirely, fix all the dead code
found on the way, and migrate *and* enlarge the PIN dialog.

- Shared theme additions (`SSP/ui/theme.py`, `SSP/ui/widgets.py`): added
  token-built `GROUPBOX_QSS` / `INPUT_QSS` / `TABLE_QSS` / `TAB_QSS` so
  per-screen code stays declarative (mirrors the existing `CARD_QSS` /
  `PRIMARY_BUTTON_QSS` shape), plus `severity_color(value, warn_at, crit_at)`
  returning the danger/warning/success token for a supply level. New
  `DangerButton` widget — filled-red, `PrimaryButton` footprint — for
  genuine override/error actions only, keeping the "red = errors only" rule
  from the earlier phases.

- admin (`screens/admin/view.py`, `screens/admin/controller.py`): rewritten
  onto `Header` + white body + `GROUPBOX_QSS` groups, 44px stepper buttons,
  `BackButton` ("Back to Main Screen") and a `SecondaryButton` ("View Data
  Logs"). Collapsed the duplicate `update_paper_count_display` /
  `update_coin_count_display` definitions (the dead ones referenced
  `self.*_input` widgets that never existed). Low-supply warnings were
  computed but never applied — `severity_color` now tints the paper/coin
  count labels and the CMYK field borders by level (paper/coin warn 50 /
  crit 20, ink warn 25 / crit 10, matching `admin/model.py`). Controller no
  longer builds or passes a background path.

- data_viewer (`screens/data_viewer/view.py`,
  `screens/data_viewer/controller.py`): rewritten onto `Header` + white body
  + `TAB_QSS` / `TABLE_QSS` light palette (was a dark-green tab bar over
  white tables), `BackButton` ("Back to Admin"). Deleted the dead
  `get_button_style`. Controller drops the background path.

- thank_you (`screens/thank_you/view.py`, `screens/thank_you/controller.py`,
  `screens/thank_you/model.py`): rewritten onto `Header` + centred white
  body + token status colours — `model.get_status_style` now maps
  printing/waiting/completed/error to the text/warning/success/danger tokens
  instead of bootstrap hex — with a `DangerButton` "Admin Override".
  Removed the hidden-but-still-wired "Simulate Print Finished" button
  entirely (widget, `finish_button_clicked` signal, `get_finish_button_style`,
  controller `_finish_printing` + its connect); the public
  `ThankYouController.finish_printing()` is kept — `main_app.py` still calls
  it.

- pin_dialog (`screens/dialogs/pin_dialog/view.py`): migrated + enlarged for
  the 1920x1080 kiosk — fixed 320x450 popup to 460x640, token-built QSS
  replacing the four `get_*_style` helpers, 76px keypad keys, digits as
  neutral buttons with a `COLORS['primary']` fill on the checkmark key.

- Background PNGs removed app-wide (`screens/{idle,homepage,wifi,email,scanner}/view.py`,
  `screens/idle/model.py`, `screens/idle/controller.py`): these five screens
  still layered the shared `Header` over a now-blank leftover PNG via
  `QStackedLayout(StackAll)`. All collapsed to a plain `QVBoxLayout(self)` +
  `Header` + white body; `background_label` / `_load_background_image` /
  `paintEvent` / `get_base_dir` and the `QPixmap` / `QPainter` /
  `QStackedLayout` imports deleted. `idle/model.py` lost
  `background_image_path` / `_load_background_image` /
  `get_background_image_path` / the `background_image_loaded` signal;
  `idle/controller.py` lost the matching connect.

- Asset deletion (`SSP/assets/*background*.png`): all 12 files deleted;
  `SSP/assets/` now holds only `icons/`. A repo-wide grep confirmed the only
  references were the screen views edited here — nothing in `tests/`,
  `webapp/`, or `managers/`.

`make test` -> 75 passed. `make lint` is clean on every authored/rewritten
file at `--max-line-length=120` (whole-repo lint still reports the
pre-existing W293/E302/E722/F541 baseline in files only line-edited here).

round-trips against the DB, `data_viewer` tables with real rows, the
