Redesign idle/homepage/wifi/email/scanner UI, fix real-resolution display

Notion-inspired visual redesign of the kiosk GUI, done pilot-first: idle
and homepage landed first and were validated before the same pattern was
rolled out to wifi/email/scanner. Not tied to a roadmap-planning.txt
phase — this is UI/UX polish on top of the already-implemented intake
pipeline, not new pipeline functionality.

- Shared design system (ui/theme.py, ui/widgets.py, ui/icons.py, new):
  design tokens (COLORS/SPACING/RADIUS/FONT) folded into QSS via
  f-strings, since Qt Style Sheets have no var()/custom-property
  support. Widgets scoped with setObjectName() so rules like :hover
  can't leak across screens. Centralizes Header, Card (replacing three
  copy-pasted ClickableCard classes), PrimaryButton/SecondaryButton,
  and this phase's new BackButton/StatusBanner. Single light theme by
  design — fixed-hardware kiosk, no user theme setting to serve.

- Baked-in banner removal (assets/*_screen background.png): the
  green/gold banner on every screen turned out to be painted directly
  into the background PNGs, not a Qt widget. Erased via PIL, measuring
  each banner's exact pixel extent before painting over it and
  re-verifying pure white afterward.

- Real kiosk resolution (main_app.py): replaced hardcoded
  setGeometry(100, 100, 1280, 720) with
  QApplication.primaryScreen().geometry() so the app targets whatever
  display it actually runs on (real hardware is 1920x1080) instead of
  an assumed resolution. global_timer_label's position is now computed
  from the window width instead of a hardcoded x=1040.

- Homepage layout (screens/homepage/view.py): cards rearranged into a
  2x2 grid per feedback; fixed content clipping past the bottom of the
  screen by replacing fixed addSpacing() calls with addStretch(), which
  was overflowing on screens shorter than the layout was tuned for.

- Rollout phase — wifi/email/scanner (screens/{wifi,email,scanner}/view.py):
  rewritten onto the shared ui/ package (Header, BackButton, Card,
  StatusBanner), deleting all three copies of the local ClickableCard
  class. Card gained an extra_widget param so wifi/email's "Enter Code"
  card can embed its OTP input + Send button. Fixed a duplicate
  send_otp_clicked signal declaration in both wifi and email views, and
  gave scanner a busy-state disable on its Start Scan card so it can't
  be re-tapped mid-scan. All three screens' controllers/models were
  re-verified against the rewritten views and needed zero changes.

- Dead code removal (screens/dialogs/payment_suggestion_dialog/,
  deleted): a 500x400 popup superseded by payment/view.py's inline
  suggestion_label, per an existing comment in payment/controller.py
  confirming the popup path was already retired. Zero remaining
  references confirmed via repo-wide grep before deletion.

75 tests passing (no new test coverage added — this is a UI-layer
change with no new business logic); lint clean on every touched file.
See KIOSK_UI_REDESIGN_SESSION_SUMMARY.md for full details, a testing
guide, and follow-up work (Phase B: usb/print_options/file_browser/
payment; Phase C: admin/data_viewer/thank_you/PIN dialog).
